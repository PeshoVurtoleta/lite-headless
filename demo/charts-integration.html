@zakkster/lite-headless x lite-charts · integration demo

A canvas chart from lite-charts wired to lite-headless overlays and controls through its lite-signal facades — a DOM hover-card tooltip on a lite-floating virtual anchor, a checkbox-group legend bound to seriesVisibility, keyboard exploration driving moveCrosshair, an aria-live announcer, a data-table fallback, and refreshTheme() on the theme toggle. Nothing here changes either library.

How it is wired: the chart is built with tooltip:false and legend:false; the crosshair signal drives the hover-card position via virtualRef.setPoint; the checkbox-group's valuechange calls chart.setSeriesVisible; arrow keys call chart.moveCrosshair at xScale.map(sample.x); the theme toggle calls chart.refreshTheme(). See docs/recipes/lite-charts-*.md for the standalone recipes.
